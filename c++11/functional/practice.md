# Практика: function, bind и делегаты (C++11)

Сначала прочитай [заметки](notes.md), затем собери [примеры](examples.cpp).
Решения сохраняй в своём `practice.cpp` рядом с этим файлом; для сборки
используй прямую команду из заметок, заменив имя исходного файла.
Ниже задания, а готовая демонстрация находится отдельно, чтобы можно было
решить их самостоятельно.

## 1. Предсказать результат

До запуска `examples.cpp` запиши:

- Что выведут `function`, `functor`, `lambda` и `pipeline`?
- Почему после вызова `copied(5)` исходный счётчик не меняется?
- Каким будет счётчик после `referenced`, вызова через `.*` и `unbound`?
- Почему `next()` и `next_copy()` вернут одинаковое число?
- Что произойдёт при вызове пустой обёртки и после снятия подписки?

Затем сравни прогноз с выводом и объясни каждое расхождение.

## 2. Один тип — три обработчика

Создай `std::function<int(int)>`. По очереди сохрани в ней свободную
функцию удвоения, функтор умножения на 3 и лямбду с захваченным смещением 10.
При аргументе 4 получи **8, 12, 14**. Объясни, почему обычная переменная
`auto`, созданная из первой лямбды, не принимает другую лямбду присваиванием.
Очисти обёртку и проверь её через `if` перед следующим вызовом.

## 3. Привязка и перестановка

Напиши `int formula(int a, int b, int c)`, возвращающую `100*a + 10*b + c`.
Через `std::bind` создай `f(x, y) = formula(y, 5, x)`.
Проверь **f(2, 3) == 352** и **f(4, 1) == 154**.
Перепиши через лямбду и объясни значения `_1` и `_2`.

## 4. Копия или ссылка

Для `Counter{10}` создай два обработчика `add`: с копией объекта и с
`std::ref`. Вызови каждый с аргументом 7 и после каждого вызова выведи
исходный `total`: ожидаются **10 и 17**.
Сделай вариант с указателем и вариант с лямбдой `[&counter]`.
Объясни, какие обработчики нельзя безопасно вызвать после разрушения `counter`.
Дополнительно свяжи `const`-метод чтения через `std::cref` и объясни,
почему через него нельзя привязать неконстантный `add`.

## 5. Делегат события

Самостоятельно напиши `Button` с единственным обработчиком
`std::function<void(int)>`: установка, вызов, замена и снятие подписки.
Подпиши метод `Counter::add` через лямбду.
Клики 2 и 3 должны дать **5**; после отписки клик 100 оставляет **5**.
Затем замени обработчик свободной функцией журналирования.
Объясни, почему второй `set_handler()` заменяет первую подписку.

## 6. Найти ошибку времени жизни

Разбери `broken()` из заметок без запуска опасного кода.
Исправь функцию так, чтобы возвращённый обработчик безопасно возвращал 42.
Объясни, почему копирование `std::function` со ссылкой не исправляет ошибку.
Придумай безопасный порядок создания, вызова и разрушения объектов для `[this]`.

## 7. Мини-проект: очередь команд

Сделай очередь `std::vector<std::function<void()>>`.
Поставь в неё три команды: прибавить 2 к счётчику, прибавить 3,
напечатать результат. При постановке команд счётчик остаётся **0**,
после выполнения очереди равен **5**.

Хотя бы одну команду создай через `std::bind`, другую — через лямбду.
Перед повторным запуском очисти очередь; объясни, что случится,
если вместо этого исполнить её второй раз. Все связанные объекты
должны жить до окончания выполнения команд.

Усложнение: добавь именованные команды через
`std::map<std::string, std::function<void()>>` и выбор команды по имени.
Не используй `operator[]` для неизвестного имени с последующим безусловным
вызовом: сначала найди запись через `find`.

## Критерий усвоения

- [ ] Различаю хранение обработчика (`function`) и привязку аргументов (`bind`).
- [ ] Могу объяснить указатель на метод и необходимость экземпляра объекта.
- [ ] Различаю копию, ссылку и владение захваченными данными.
- [ ] Пишу обработчик события с проверкой пустоты и снятием подписки.
- [ ] Знаю, что материалы относятся к C++11, а `std::invoke` и `bind_front` — к C++17 и C++20.
- [ ] Могу выбрать между `auto`, шаблоном, указателем на функцию и `std::function`.
