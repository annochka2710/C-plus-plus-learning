# C++17

Краткий план изучения основных нововведений относительно C++14.
Для каждой темы — небольшой пример и сравнение с прежним подходом.

## Язык

- [ ] Структурированные привязки: `auto [key, value]`.
- [ ] Начальная инструкция в `if` и `switch`.
- [ ] `if constexpr` — выбор ветки во время компиляции.
- [ ] Fold expressions — свёртка пакета параметров шаблона.
- [ ] CTAD — вывод аргументов шаблона класса.
- [ ] `auto` в нетиповых параметрах шаблона.
- [ ] Inline-переменные и определение общих констант в заголовках.
- [ ] Гарантированное устранение копирования в определённых случаях; отличие от NRVO.
- [ ] Атрибуты `[[nodiscard]]`, `[[maybe_unused]]`, `[[fallthrough]]`.
- [ ] Захват `*this` в лямбде — копия объекта вместо указателя.

## Стандартная библиотека

- [ ] `std::optional` — значение, которое может отсутствовать.
- [ ] `std::variant` и `std::visit` — один из нескольких заданных типов.
- [ ] `std::any` — хранение значения произвольного копируемого типа.
- [ ] `std::string_view` — представление строки без владения и время жизни данных.
- [ ] `std::filesystem` — пути, каталоги и операции с файлами.
- [ ] `std::invoke` и `std::apply` — вызов функций и распаковка кортежей.
- [ ] `std::from_chars`, `std::to_chars` — преобразование чисел и текста.
- [ ] `std::clamp`, `std::gcd`, `std::lcm` и `std::byte`.
- [ ] `try_emplace`, `insert_or_assign`, `extract` и `merge` у ассоциативных контейнеров.
- [ ] Параллельные алгоритмы и политики выполнения `std::execution`.
