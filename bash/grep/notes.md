# Команда grep

`grep` ищет строки, соответствующие шаблону, внутри текста.
По умолчанию выводит всю найденную строку и учитывает регистр.
`find` ищет файлы и каталоги, а `grep` — строки в их содержимом.

Все команды ниже выполняются из корня проекта в Linux.
Учебные файлы находятся в `bash/practice/grep/`.

## Синтаксис

```bash
grep 'шаблон' путь_к_файлу
```

Найти строки, содержащие `ERROR`:

```bash
grep 'ERROR' bash/practice/grep/app.log
```

По умолчанию достаточно совпадения в любой части строки:
найдутся как `ERROR connection failed`, так и `ERRORS summary available`.
Строка с маленькими буквами `error` не найдётся.

Шаблон заключаем в одинарные кавычки, чтобы оболочка передала его
команде без подстановок. Сами кавычки в шаблон не входят.

## Основные опции

| Опция | Назначение |
|---|---|
| `-n` | Показать номера строк, начиная с 1 |
| `-i` | Не учитывать регистр |
| `-w` | Искать совпадение как отдельное слово |
| `-v` | Вывести строки, которые не соответствуют шаблону |
| `-c` | Посчитать строки с совпадениями для каждого файла |
| `-l` | Вывести только имена файлов с совпадениями |
| `-r` | Искать в каталоге и его подкаталогах |
| `-F` | Считать шаблон обычным текстом |
| `-E` | Использовать расширенные регулярные выражения |

Опции можно объединять: `-inw` означает `-i -n -w`.

```bash
grep -inw 'error' bash/practice/grep/app.log
```

Этот пример найдёт `ERROR` и `error`, но не `ERRORS` и не `error_count`.
Для `-w` буквы, цифры и символ `_` считаются символами слова.

`-c` считает строки, а не отдельные вхождения: два совпадения
в одной строке увеличат результат только на 1.

## Поиск в нескольких файлах и каталогах

```bash
grep -l 'ERROR' bash/practice/grep/app.log bash/practice/grep/notes.txt
grep -rn --include='*.log' 'ERROR' bash/practice/grep
```

В первом примере выводятся только имена файлов с совпадениями.
Во втором поиск идёт по дереву каталогов, но только в файлах,
имена которых соответствуют `*.log`. В выводе будут пути и номера строк.

У `--include` шаблон имени файла, а у `grep` — отдельный шаблон
для поиска в содержимом. Это разные условия.

## Обычный текст и регулярные выражения

По умолчанию шаблон `grep` — базовое регулярное выражение.
Некоторые символы в нём имеют специальный смысл.

Например, точка `.` означает любой один символ:

```bash
grep '1.2' bash/practice/grep/config.txt
```

Найдутся строки и с `1.2`, и с `1x2`.
Для поиска буквального текста используем `-F`:

```bash
grep -F '1.2' bash/practice/grep/config.txt
```

Здесь найдётся только строка с `1.2`.

Ещё несколько элементов регулярных выражений:

| Элемент | Значение |
|---|---|
| `^` | Начало строки |
| `$` | Конец строки |
| `[0-9]` | Одна цифра от 0 до 9 |
| `*` | Ноль или больше повторений предыдущего элемента |

В регулярном выражении `*` относится к предыдущему элементу.
Это отличается от `*` в шаблоне имени файла у `find`.

```bash
grep -v '^INFO ' bash/practice/grep/app.log
grep -n 'stopped$' bash/practice/grep/app.log
grep -En '^(ERROR|WARNING) ' bash/practice/grep/app.log
```

Первый пример исключает строки, начинающиеся с `INFO `.
Второй ищет `stopped` в конце строки.
Третий использует расширенный синтаксис (`-E`): скобки группируют
варианты, а `|` означает «ИЛИ». После уровня сообщения требуется пробел,
поэтому строка с `ERRORS` не подойдёт.

## Если ничего не найдено

Обычно `grep` ничего не выводит, если подходящих строк нет.
Его код завершения позволяет отличить такой результат от ошибки:

- `0` — есть совпадения;
- `1` — совпадений нет;
- `2` — произошла ошибка, например указанный файл не существует.

Отсутствие совпадений — обычный результат поиска.

## Практика

1. Найди строки с `INFO` и выведи их номера.
2. Сравни поиск `error` с опцией `-i` и с сочетанием `-iw`.
3. Посчитай строки, начинающиеся с `INFO `.
4. Найди `ERROR` во всех `.log` файлах, включая `services/worker.log`.

## Запуск примеров

```bash
bash bash/grep/examples.sh
```

Скрипт читает учебные файлы и выводит результаты. Их содержимое не меняется.
