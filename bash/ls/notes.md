# Команда ls

`ls` показывает содержимое каталогов и сведения о файлах.
Без пути просматривает текущий каталог. Обычно имена сортируются
по алфавиту с учётом текущей локали, а скрытые имена пропускаются.

Ниже — наиболее полезные флаги GNU-совместимой `ls` в Linux.
Короткие опции можно объединять: `-lah` означает `-l -a -h`.

## Синтаксис

```bash
ls
ls bash
ls -lh -- bash/README.md
```

Можно передавать несколько путей. Для обычного файла `ls` показывает
его имя или свойства, для каталога — его содержимое.
Опция `-d` меняет поведение для каталога: показывает его самого.

`--` завершает список опций. Например, в каталоге с файлом `-draft.txt`
команда `ls -l -- -draft.txt` не примет имя файла за опцию.
Кавычки вокруг пути нужны, если в нём есть пробелы или другие
символы, которые оболочка могла бы обработать отдельно.

## Подготовка практики

Из корня проекта выполни блок в Bash. Все следующие примеры с переменной
`work_dir` выполняй в этой же оболочке:

```bash
work_dir=$(mktemp -d /tmp/bash-ls.XXXXXX)
printf 'Учебный каталог: %s\n' "$work_dir"
mkdir -p "$work_dir/docs/nested" "$work_dir/empty"
printf 'Small\n' > "$work_dir/small.txt"
printf '%2048s' '' > "$work_dir/large.txt"
printf 'Hidden\n' > "$work_dir/.hidden.txt"
printf 'Report\n' > "$work_dir/report final.txt"
printf 'Draft\n' > "$work_dir/-draft.txt"
printf 'Notes\n' > "$work_dir/docs/nested/notes.txt"
printf '#!/usr/bin/env bash\n' > "$work_dir/run.sh"
chmod u+x -- "$work_dir/run.sh"
for number in 1 2 10; do
    printf 'v%s\n' "$number" > "$work_dir/part-$number.txt"
done
ln -- "$work_dir/small.txt" "$work_dir/hard-small.txt"
ln -s -- small.txt "$work_dir/file-link"
ln -s -- docs "$work_dir/directory-link"
touch -t 202001010000 -- "$work_dir/small.txt"
touch -t 202101010000 -- "$work_dir/large.txt"
```

Скрипт в конце модуля сам создаёт такой набор и удаляет его при выходе.
`large.txt` содержит 2048 пробелов. Даты двух файлов заданы специально,
чтобы порядок сортировки по времени был заметен при каждом запуске.

## Основные флаги

| Флаг | Назначение |
|---|---|
| `-l` | Подробные сведения о каждом объекте |
| `-h` | Удобные единицы размера с `-l` или `-s`: `K`, `M`, `G` |
| `-a` | Показать скрытые имена, включая `.` и `..` |
| `-A` | Показать скрытые имена, кроме `.` и `..` |
| `-1` | Одно имя на строку; это цифра один |
| `-d` | Показать сам каталог вместо его содержимого |
| `-R` | Рекурсивно просмотреть подкаталоги |
| `-F` | Добавить обозначение типа: `/` у каталога, `@` у ссылки, `*` у исполняемого файла |
| `-p` | Добавить `/` к именам каталогов |
| `-i` | Показать номера inode |

### Скрытые файлы: -a и -A

```bash
ls -1 -- "$work_dir"
ls -1a -- "$work_dir"
ls -1A -- "$work_dir"
```

`.hidden.txt` виден в двух последних командах. `.` обозначает сам каталог,
`..` — родительский; только `-a` добавляет их в вывод списка каталога.
Для ежедневного просмотра часто удобна комбинация `ls -lAh`.

В терминале обычная `ls` может раскладывать имена по столбцам,
а при перенаправлении вывода — по одному на строке. `-1` задаёт формат явно.

### Как читать ls -l

```bash
ls -l -- "$work_dir/small.txt"
ls -lh -- "$work_dir/large.txt"
```

Пример структуры строки; имена владельца и дата условные:

```text
-rw-r--r-- 2 user group 6 Jan  1  2020 small.txt
```

| Часть | Значение |
|---|---|
| `-` в начале | Тип объекта: `-` — обычный файл, `d` — каталог, `l` — символическая ссылка |
| `rw-r--r--` | Права владельца, группы и остальных |
| `2` | Число жёстких ссылок на inode |
| `user`, `group` | Владелец и группа |
| `6` | Логический размер обычного файла в байтах |
| `Jan 1 2020` | По умолчанию время изменения содержимого, `mtime` |
| `small.txt` | Имя; для символической ссылки также показывается `-> цель` |

Права могут сопровождаться дополнительной отметкой, например `+` для ACL.
Формат даты зависит от локали и возраста файла.

`-h` делает размер удобным для чтения: для нашего файла получится около `2K`.
Используются степени 1024. Для степеней 1000 существует `--si`.
Сам по себе `ls -h` не добавляет столбец размера: обычно нужен `ls -lh`.

### Каталог и содержимое: -d и -R

```bash
ls -l -- "$work_dir/docs"
ls -ldh -- "$work_dir/docs"
ls -R -- "$work_dir/docs"
```

Первая команда показывает объекты внутри `docs`, вторая — свойства самого
каталога, третья — всё дерево `docs`, включая `nested/notes.txt`.
Для скрытых имён при рекурсивном просмотре добавь `-a` или `-A`.

Размер каталога в `ls -ldh` описывает сам каталог, а не сумму размеров
всех вложенных файлов. Для занятого деревом места используют `du -sh`.
Строка `total` в длинном выводе каталога показывает выделенные блоки
перечисленных объектов, а не число файлов.

## Сортировка

| Флаг | Порядок |
|---|---|
| `-t` | По времени, обычно `mtime`: сначала новые |
| `-S` | По размеру: сначала большие |
| `-r` | Развернуть текущий порядок сортировки |
| `-v` | Учитывать числа в именах: `part-2` раньше `part-10` |
| `-X` | По расширению имени |
| `-U` | Не сортировать, оставить порядок записей каталога |

```bash
ls -lhS -- "$work_dir/small.txt" "$work_dir/large.txt"
ls -lhSr -- "$work_dir/small.txt" "$work_dir/large.txt"
ls -lt -- "$work_dir/small.txt" "$work_dir/large.txt"
ls -ltr -- "$work_dir/small.txt" "$work_dir/large.txt"
ls -1v -- "$work_dir"/part-*.txt
```

В первых двух командах меняется порядок размеров. В следующих двух —
порядок дат: с `-t` сначала файл 2021 года, с `-tr` — 2020 года.
`-r` без других флагов сортировки разворачивает порядок имён.
Опция `-R` с большой буквой означает рекурсивный просмотр и к `-r`
отношения не имеет.

Шаблон `part-*.txt` раскрывает Bash до запуска `ls`. Кавычки защищают
путь из переменной, а `*` оставлен снаружи кавычек для подстановки имён.
Если совпадений нет, при обычных настройках Bash `ls` получит буквальный
шаблон и сообщит об отсутствующем пути.

## Типы, inode и символические ссылки

```bash
ls -1F -- "$work_dir"
ls -1p -- "$work_dir"
ls -li -- "$work_dir/small.txt" "$work_dir/hard-small.txt" "$work_dir/file-link"
ls -lL -- "$work_dir/file-link"
ls -ld -- "$work_dir/directory-link"
```

`-i` добавляет номер inode перед остальными полями. У двух жёстких имён
номер одинаковый, у символической ссылки — отдельный.
С `-lL` показаны свойства цели ссылки; с `-l` без `-L` — самой ссылки.

`ls -ld directory-link` показывает ссылку на каталог.
Обычная `ls directory-link` может показывать содержимое целевого каталога.
Учитывай это при выборе флагов.

Метки `-F` и `-p` добавляются только к выводу, а не к настоящим именам.
Подробности устройства ссылок — в [модуле inode и ссылки](../../linux/links/notes.md).

## Другие полезные опции

| Опция | Назначение |
|---|---|
| `-L` | Показывать свойства целей символических ссылок |
| `-n` | Длинный формат с числовыми UID/GID вместо имён владельца и группы |
| `-s` | Добавить выделенное место в блоках; единицы можно задавать отдельно |
| `-Q` | Показывать имена в двойных кавычках |
| `-b` | Показывать непечатаемые символы через escape-последовательности |
| `--color=auto` | Добавлять цвет, когда вывод направлен в терминал |
| `--color=never` | Отключить цветовые коды |
| `--group-directories-first` | Сначала каталоги, затем остальные объекты |
| `--time-style=long-iso` | В длинном формате показывать дату как `YYYY-MM-DD HH:MM` |

```bash
ls -n -- "$work_dir/small.txt"
ls -lsk -- "$work_dir/large.txt"
ls -lQ -- "$work_dir/report final.txt"
ls -lb -- "$work_dir/report final.txt"
ls -lAh --group-directories-first --color=auto -- "$work_dir"
ls -l --time-style=long-iso -- "$work_dir/small.txt"
```

В `-lsk` первый числовой столбец показывает выделенное место в блоках
по 1024 байта (`-k`), а столбец размера из `-l` по-прежнему содержит байты.
Логический размер и выделенное место могут различаться.

Для других временных меток есть `-u` и `-c`:

```bash
ls -lu -- "$work_dir/small.txt"
ls -lc -- "$work_dir/small.txt"
```

С `-lu` выводится `atime`, с `-lc` — `ctime`. Для сортировки по ним добавляют
`-t`, например `-ltu` или `-ltc`. **`ctime` — изменение состояния inode,
а не время создания файла.**

## Шпаргалка

| Команда | Для чего |
|---|---|
| `ls -lAh` | Подробно, со скрытыми именами и удобными размерами |
| `ls -lt` | Недавно изменённые объекты в начале |
| `ls -ltr` | Недавно изменённые объекты в конце |
| `ls -lhS` | Большие файлы в начале |
| `ls -ld каталог` | Права и свойства самого каталога |
| `ls -li файл` | Свойства и номер inode |
| `ls -1F` | Одно имя на строку с метками типов |

Не используй разбор текста `ls` как универсальный способ обработки имён
в скрипте: имя может содержать даже перевод строки. Для обработки путей
подходят, например, `find -print0` и инструменты с поддержкой NUL-разделителя.
Цвет, кавычки и формат вывода также могут зависеть от настроек и алиасов;
проверить команду можно через `type ls`.

## Практика

1. Сравни `-a` и `-A`. Почему в одном выводе есть `.` и `..`?
2. Найди в `ls -l` права, владельца, размер и число жёстких ссылок.
   Сравни `small.txt`, `hard-small.txt` и `file-link`.
3. Выведи сначала большие файлы, затем маленькие. Сравни `-r` и `-R`.
4. Сравни обычный порядок имён `part-*.txt` и порядок с `-v`.
5. Покажи свойства `docs`, затем его содержимое, затем всё дерево.
6. Сравни `-l` и `-lL` для `file-link`. Как меняются тип, размер и inode,
   если добавить также `-i`?
7. Сравни логический размер и выделенное место через `ls -lsk`.
   Почему размер каталога не равен размеру всех вложенных файлов?

После ручных примеров проверь путь и удали учебный каталог:

```bash
printf '%s\n' "$work_dir"
rm -r -- "$work_dir"
unset work_dir
```

## Запуск примеров и справка

Из корня проекта:

```bash
bash bash/ls/examples.sh
```

Скрипт создаёт данные во временном каталоге и удаляет его при выходе.
`LC_ALL=C` задаёт предсказуемую сортировку для демонстрации.
Файлы проекта не меняются.

Полный список флагов: `ls --help`, `man ls` или [руководство ls(1)](https://man7.org/linux/man-pages/man1/ls.1.html).
Некоторые длинные опции отличаются в других реализациях, например BSD/macOS.
