# Удаление файлов и каталогов

`rm` удаляет файлы и деревья каталогов, а `rmdir` — только пустые каталоги.
Обычно эти команды ничего не выводят при успешном выполнении.
Опция `-v` позволяет увидеть, что было удалено.

Команды ниже предназначены для Bash в Linux. Примеры используют
возможности GNU `rm` и `find`.

## Подготовка учебных файлов

В отличие от модулей с поиском, здесь будем менять данные. Создадим
отдельный временный каталог, чтобы не удалять файлы проекта:

```bash
work_dir=$(mktemp -d /tmp/bash-rm.XXXXXX)
printf 'Учебный каталог: %s\n' "$work_dir"
```

`mktemp -d` создаёт каталог с уникальным именем и выводит его путь.
Конструкция `$(...)` сохраняет этот вывод в переменную `work_dir`.
Все следующие примеры выполняй в той же оболочке, чтобы переменная сохранилась.

`rm` не отправляет файлы в корзину. Перед удалением проверяй пути.
Удаление также не гарантирует стирания содержимого с носителя.

## Удаление файлов: rm

```bash
touch "$work_dir/first.txt" "$work_dir/second.txt" "$work_dir/report final.txt"
rm -v -- "$work_dir/first.txt"
rm -v -- "$work_dir/second.txt" "$work_dir/report final.txt"
```

Можно передать один путь или несколько. Кавычки сохраняют путь с пробелами
как один аргумент. `--` завершает список опций: следующие аргументы
считаются путями.

Если находишься в каталоге с файлом `-draft.txt`, удалить его можно
командой `rm -- -draft.txt` или `rm ./-draft.txt`. Одних кавычек
в `rm '-draft.txt'` недостаточно: имя всё равно начинается с `-`.

## Основные опции rm

| Опция | Назначение |
|---|---|
| `-v` | Вывести удаляемые пути |
| `-i` | Спрашивать подтверждение перед каждым удалением |
| `-I` | Спросить один раз при удалении более трёх файлов или при рекурсивном удалении |
| `-r`, `-R` | Удалить каталог вместе с его содержимым |
| `-d` | Удалить пустой каталог |
| `-f` | Не спрашивать подтверждение и не считать отсутствие файла ошибкой |

Для ручного удаления с подтверждением:

```bash
touch "$work_dir/draft.txt"
rm -i -- "$work_dir/draft.txt"
```

Ответ `y` подтверждает удаление, `n` оставляет файл. Если отказался,
`draft.txt` останется до очистки учебного каталога в конце модуля.

Без `-f` отсутствие указанного файла вызывает ошибку.
С `-f` повторное удаление уже отсутствующего файла допустимо:

```bash
rm -f -- "$work_dir/missing.txt"
```

`-f` не обходит права доступа. Сочетание `-rf` означает рекурсивное
удаление без запросов подтверждения; для обычного удаления дерева
достаточно `-r`, если принудительное удаление не требуется.

## Удаление каталога с содержимым

```bash
mkdir -p "$work_dir/cache/nested"
touch "$work_dir/cache/nested/data.txt"
rm -rv -- "$work_dir/cache"
```

Без `-r` команда `rm` по умолчанию откажется удалять каталог.
С `-r` она удаляет вложенные файлы и каталоги, включая скрытые,
а затем сам указанный каталог.

## Удаление пустых каталогов: rmdir

```bash
mkdir "$work_dir/empty"
rmdir -v -- "$work_dir/empty"
```

Если внутри есть хотя бы один файл или подкаталог, `rmdir` завершится
с ошибкой и оставит каталог. Скрытые файлы тоже делают каталог непустым.
Для пустого каталога также подходит `rm -d`.

Опция `-p` удаляет указанную цепочку каталогов снизу вверх, пока они пусты:

```bash
mkdir -p "$work_dir/parents/child/leaf"
(
    cd -- "$work_dir" || exit 1
    rmdir -pv -- parents/child/leaf
)
```

Будут удалены `leaf`, затем `child`, затем `parents`.
Скобки запускают команды в подоболочке: смена каталога не затронет
текущую оболочку. Относительный путь ограничивает цепочку каталогом
`parents`: передавать весь абсолютный путь с `-p` здесь не нужно.

## Символические ссылки и unlink

```bash
touch "$work_dir/original.txt"
ln -s -- "$work_dir/original.txt" "$work_dir/shortcut"
rm -v -- "$work_dir/shortcut"
```

Удалена ссылка `shortcut`, а `original.txt` остался. Для ссылки на каталог
также указывай имя самой ссылки без завершающего `/`.

`unlink` удаляет ровно один файл или символическую ссылку.
Рекурсивного удаления у него нет:

```bash
unlink -- "$work_dir/original.txt"
```

Для повседневной работы обычно удобнее `rm`, поскольку он принимает
несколько путей и поддерживает подтверждения.

## Удаление по условию: find -delete

Сначала выведем подходящие файлы, затем удалим их с теми же условиями:

```bash
mkdir -p "$work_dir/logs/archive"
touch "$work_dir/logs/current.log" "$work_dir/logs/archive/old.log"
touch "$work_dir/logs/keep.txt"
find "$work_dir/logs" -type f -name '*.log' -print
find "$work_dir/logs" -type f -name '*.log' -delete
```

Будут удалены оба `.log` файла; `keep.txt` и каталоги останутся.
`-type f` ограничивает удаление обычными файлами. Шаблон в кавычках
обрабатывает `find`, а не Bash.

`-delete` удаляет найденные объекты без подтверждения и автоматически
включает обход в глубину (`-depth`): содержимое обрабатывается раньше
родительского каталога. Не сочетай его с `-prune`: при таком обходе
исключение поддерева через `-prune` не работает.

## Шаблоны имён и скрытые файлы

В команде `rm -- каталог/*.log` шаблон раскрывает Bash до запуска `rm`.
В обычных настройках `*` не захватывает имена, начинающиеся с точки.
Если совпадений нет, Bash обычно передаёт шаблон буквально, и `rm`
сообщает об отсутствующем файле. Настройки `dotglob`, `nullglob`
и `failglob` могут менять это поведение.

`rm -r -- каталог` удаляет весь указанный каталог, включая скрытое
содержимое: здесь обход выполняет сама команда `rm`.
У `find -name '*.log'` шаблон может совпасть и со скрытым `.hidden.log`.

## Очистка после ручных примеров

Проверь, что переменная указывает на созданный в начале учебный каталог:

```bash
printf '%s\n' "$work_dir"
rm -r -- "$work_dir"
unset work_dir
```

## Практика

1. Создай новый временный каталог через `mktemp -d` и файл с пробелом в имени.
   Удали файл с опциями `-iv`.
2. Создай непустой каталог. Сравни результат `rmdir` и `rm -r`.
3. Создай файл и две символические ссылки на него. Удали одну через `rm`,
   вторую через `unlink` и проверь, что исходный файл остался.
4. Создай `.tmp` и `.txt` файлы, включая скрытый `.hidden.tmp`.
   Через `find` сначала выведи, затем удали только обычные `.tmp` файлы.
   После упражнений удали свой временный каталог.

## Запуск примеров

Из корня проекта:

```bash
bash bash/rm/examples.sh
```

Скрипт сам создаёт временный каталог в `/tmp` и удаляет его при выходе.
Файлы проекта он не меняет. Подтверждения `-i` и `-I` оставлены
для ручной практики, чтобы скрипт выполнялся без ввода.
