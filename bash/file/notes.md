# Команда file

`file` определяет тип файла по содержимому и характерным признакам
формата. Расширение файла может не соответствовать содержимому.

Все команды ниже выполняются из корня проекта.

## Синтаксис

```bash
file путь_к_файлу
```

Можно проверить несколько файлов:

```bash
file bash/practice/file/message.txt bash/practice/file/picture.jpg
```

Оба учебных файла содержат текст `Hello, Linux!`, поэтому результат
для каждого — `ASCII text`, даже если один имеет расширение `.jpg`.

Команда также распознаёт каталоги и пустые файлы:

```bash
file bash/practice/file
file bash/practice/file/empty
```

Ожидаемые описания: `directory` и `empty`.

## Основные опции

| Опция | Назначение |
|---|---|
| `-b` | Вывести описание без имени файла |
| `--mime-type` | Вывести MIME-тип |
| `--mime-encoding` | Вывести предполагаемую кодировку |
| `--mime` | Вывести MIME-тип и кодировку |

## MIME-тип и кодировка

MIME-тип — стандартное обозначение типа содержимого.
Формат: `тип/подтип`. Его используют, например, браузеры и почтовые программы.

| MIME-тип | Содержимое |
|---|---|
| `text/plain` | Обычный текст |
| `text/html` | HTML-документ |
| `image/jpeg` | Изображение JPEG |
| `image/png` | Изображение PNG |
| `application/pdf` | PDF-документ |
| `application/octet-stream` | Произвольные двоичные данные |

MIME-тип описывает вид содержимого, а кодировка текста —
способ представления символов байтами.

```bash
file --mime bash/practice/file/picture.jpg
```

Ожидаемый результат:

```text
bash/practice/file/picture.jpg: text/plain; charset=us-ascii
```

Здесь:

- `text/plain` — обычный текст;
- `charset=us-ascii` — кодировка ASCII.

## Вывод из практики

Копирование текстового файла с расширением `.jpg` не превращает его
в изображение. Команда `file` по-прежнему распознаёт текст.

Определение типа и кодировки основано на проверках и эвристиках:
результат не всегда гарантированно точен.

## Запуск примеров

```bash
bash bash/file/examples.sh
```

Скрипт проверяет существующие файлы в `bash/practice/file/`.
Строка `#!/usr/bin/env bash` указывает, что скрипт предназначен для Bash.
Остальные строки, начинающиеся с `#`, — комментарии.
