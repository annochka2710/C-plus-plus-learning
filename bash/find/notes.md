# Команда find

`find` ищет файлы и каталоги по заданным условиям. Поиск начинается
с указанного пути и по умолчанию проходит по всем вложенным каталогам.
Сам начальный путь тоже проверяется.

Все команды ниже выполняются из корня проекта в Linux.
Учебные файлы находятся в `bash/practice/find/`.

## Синтаксис

```bash
find начальный_путь условия
```

Показать начальный каталог и всё его содержимое:

```bash
find bash/practice/find
```

`.` обозначает текущий каталог: `find .` начинает поиск из него.
Порядок вывода не гарантирован.

## Поиск по имени

```bash
find bash/practice/find -name '*.txt'
find bash/practice/find -iname '*.txt'
```

- `-name` проверяет имя без пути и учитывает регистр.
- `-iname` не учитывает регистр: найдёт также `NOTES.TXT`.
- `*` в шаблоне означает любую последовательность символов.

Шаблон заключаем в кавычки, чтобы его обработала команда `find`,
а оболочка не подставила вместо него имена из текущего каталога.

`find` также просматривает скрытые файлы. Шаблон `'*.txt'`
найдёт и `.hidden.txt`.

## Поиск по типу

```bash
find bash/practice/find -type f
find bash/practice/find -type d
find bash/practice/find -type f -name '*.cpp'
```

- `-type f` — обычные файлы.
- `-type d` — каталоги.
- Условия, записанные подряд, соединяются логическим «И»:
  последний пример ищет обычные файлы с именем, оканчивающимся на `.cpp`.

Без `-type f` условию `-name '*.txt'` мог бы соответствовать и каталог
с таким именем.

## Ограничение глубины

```bash
find bash/practice/find -maxdepth 1 -type f
```

Начальный каталог имеет глубину 0, его непосредственное содержимое — 1.
Этот пример покажет файлы непосредственно в учебном каталоге,
не заходя в `src/` и `logs/`.

## Поиск по размеру

```bash
find bash/practice/find -type f -size -20c
```

`c` обозначает байты. `-20c` означает строго меньше 20 байт,
`+20c` — строго больше 20 байт, `20c` — ровно 20 байт.

## Несколько вариантов имени

```bash
find bash/practice/find -type f \( -name '*.txt' -o -name '*.log' \)
```

`-o` означает логическое «ИЛИ». Скобки группируют варианты имени,
чтобы `-type f` применялось к обоим вариантам.
Обратный слеш перед каждой скобкой защищает её от обработки оболочкой.
Здесь регистр учитывается, поэтому `NOTES.TXT` не попадёт в результат.

## Передача найденных файлов команде file

```bash
find bash/practice/find -type f -exec file {} +
```

`-exec` запускает указанную команду. Вместо `{}` подставляются пути
найденных файлов, а `+` завершает выражение и позволяет передать
несколько путей одному запуску `file`.

Путь `report final.txt` с пробелом передаётся одним аргументом.

## Практика

1. Найди только файлы `.log`, включая файл во вложенном `logs/archive/`.
2. Найди файл `report final.txt` по полному имени. Используй кавычки.
3. Покажи только каталоги и сопоставь результат с деревом учебных файлов.

## Запуск примеров

```bash
bash bash/find/examples.sh
```

Скрипт выполняет поиск и выводит результаты. Учебные файлы он не меняет.
