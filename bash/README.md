# Команды Linux и Bash

Изучаем команды Linux из оболочки Bash: краткая теория, примеры и практика.

Для каждой команды: `<команда>/notes.md` — заметки,
`<команда>/examples.sh` — примеры. Учебные файлы находятся в `practice/`.
Скрипты запускаем из корня проекта: `bash bash/<команда>/examples.sh`.

## План изучения

- [x] `file` — определение типа файла и кодировки.
- [x] `find` — поиск файлов и каталогов.
- [x] `grep` — поиск строк в тексте.
- [x] [`ls`](ls/notes.md) — содержимое каталогов, свойства файлов и сортировка.
- [x] `rm`, `rmdir`, `unlink`, `find -delete` — удаление файлов и каталогов.
- [ ] `pwd`, `cd` — текущий каталог и навигация.
- [ ] `mkdir`, `touch` — создание каталогов и файлов.
- [ ] `cp`, `mv` — копирование и перемещение.
- [ ] `cat`, `less`, `head`, `tail` — просмотр содержимого файлов.
- [ ] `wc`, `sort`, `uniq` — подсчёт, сортировка и обработка повторяющихся строк.
- [ ] `cut`, `tr` — извлечение полей и преобразование символов.
- [ ] `sed`, `awk` — замена текста и обработка строк по полям.
- [ ] `diff`, `cmp` — сравнение файлов.
- [ ] `ln`, `readlink` — ссылки и их целевые пути.
- [ ] `chmod`, `chown` — права доступа и владельцы файлов.
- [ ] `du`, `df` — размер файлов и свободное место на диске.
- [x] [`ps`, `top`, `pgrep`, `kill`](../linux/processes/notes.md) — просмотр
  процессов и отправка сигналов; модуль в разделе Linux.
- [ ] `tar`, `gzip`, `gunzip` — архивирование и сжатие.
- [ ] `curl`, `wget` — запросы и загрузка файлов.
- [ ] `xargs`, `tee` — передача аргументов и сохранение вывода.
- [ ] `man`, `help`, `type`, `command -v` — справка и поиск команд.

## Возможности Bash

- [ ] Потоки ввода и вывода, перенаправления `>`, `>>`, `<`, `2>` и конвейеры `|`.
- [ ] Кавычки, экранирование и шаблоны имён файлов.
- [ ] Переменные, окружение и подстановка команд `$(...)`.
- [ ] Коды завершения, операторы `&&` и `||`.
- [ ] Условия, циклы, функции и аргументы скрипта.
