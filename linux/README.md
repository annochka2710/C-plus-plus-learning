# Устройство Linux

Изучаем, как работают файлы, файловая система и другие механизмы Linux:
краткая теория, примеры и самостоятельная практика.

Для каждой темы: `<тема>/notes.md` — заметки и упражнения,
`<тема>/examples.sh` — запускаемые примеры.
Скрипты запускаем из корня проекта: `bash linux/<тема>/examples.sh`.
Данные для экспериментов со ссылками создаются во временном каталоге.
Примеры управления процессами запускают собственные учебные процессы.

## План изучения

- [x] [Inode и ссылки](links/notes.md) — индексные дескрипторы, метаданные,
  `ln`, `stat`, `readlink`, счётчик ссылок и удаление открытого файла.
- [x] [Просмотр и завершение процессов](processes/notes.md) — `ps`, `top`,
  `pgrep`, сигналы, `kill`, `jobs` и `wait`.
- [ ] Каталоги и разрешение путей.
- [ ] Права доступа: владелец, группа, `rwx`, права на каталоги.
- [ ] Файловые системы и точки монтирования.
- [ ] Файловые дескрипторы и открытые файлы процессов.

Отметка означает, что материалы подготовлены. Для закрепления выполни
упражнения из заметок и объясни результат каждого эксперимента.

Примеры отдельных команд находятся также в [разделе Bash](../bash/README.md).
