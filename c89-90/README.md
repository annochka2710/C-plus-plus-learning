# C89 / C90

C89 — стандарт ANSI C 1989 года, C90 — его международная версия ISO
1990 года. Здесь изучаем общую для них основу языка C.
В имени каталога используем `c89-90`: символ `/` разделяет каталоги.

Для каждой темы — отдельный модуль с русскими заметками, примерами
на C и самостоятельными упражнениями. Примеры компилируем как C90,
без расширений компилятора и возможностей более поздних стандартов.

## План изучения

- [x] [volatile](volatile/notes.md) — обращения к объекту, оптимизации,
  указатели и флаг обработчика сигнала.
- [ ] Типы, объявления, выражения и преобразования.
- [ ] Указатели, массивы и строки.
- [ ] Область видимости, время хранения, `static` и `extern`.
- [ ] Квалификатор `const` и его сочетания с указателями.
- [ ] Структуры, объединения и перечисления.
- [ ] Динамическая память: `malloc`, `realloc`, `free`.

Отметка означает, что материалы подготовлены. Практика находится в заметках
к модулю; готовность объяснить результат проверяем после выполнения заданий.

## Сборка

Из корня проекта:

```bash
cmake -S . -B build
cmake --build build --target c90_volatile_examples c90_volatile_signal
```

Запуск в Linux при обычной сборке CMake:

```bash
./build/c89-90/volatile/c90_volatile_examples
./build/c89-90/volatile/c90_volatile_signal
```

Второй пример ждёт `Ctrl+C`. Команды прямой компиляции через `cc`
приведены в [заметках](volatile/notes.md).
