# C++98

Изучаем основу языка C++98: заметки на русском, запускаемые примеры
и самостоятельные упражнения. В каждом модуле — `notes.md` и `examples.cpp`.
Примеры собираются в режиме C++98 без расширений компилятора.

## План изучения

- [x] [mutable](mutable/notes.md) — изменяемые поля в `const`-объектах,
  логическая константность и кеширование результата.
- [ ] Классы, конструкторы, деструкторы и уровни доступа.
- [ ] `const`, указатели, ссылки и константные методы.
- [ ] Копирование объектов и правило трёх.
- [ ] Наследование, виртуальные функции и полиморфизм.
- [ ] Шаблоны, контейнеры и алгоритмы стандартной библиотеки.

Отметка означает, что материалы подготовлены. Выполнение упражнений
и самостоятельное объяснение результатов проверяем отдельно.

## Сборка

Из корня проекта:

```bash
cmake -S . -B build
cmake --build build --target cpp98_mutable_examples
./build/c++98/mutable/cpp98_mutable_examples
```

Путь запуска указан для обычной сборки CMake в Linux.
Команда прямой компиляции через `c++` есть в [заметках](mutable/notes.md).
