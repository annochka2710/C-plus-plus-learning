### Что нужно усвоить: find, grep и практика

Отмечать пункты после самостоятельного выполнения и объяснения результата.

#### find — поиск файлов и каталогов

- [ ] Выбирать начальный каталог поиска и понимать рекурсивный обход.
- [ ] Использовать `-name` и `-iname`, объяснять разницу в учёте регистра.
- [ ] Заключать шаблоны вроде `'*.txt'` в кавычки и объяснять зачем.
- [ ] Различать файлы и каталоги через `-type f` и `-type d`.
- [ ] Ограничивать глубину через `-maxdepth` и искать по размеру через `-size`.
- [ ] Объединять условия через «И», `-o` и защищённые скобки `\(` и `\)`.
- [ ] Передавать найденные пути команде через `-exec file {} +`,
  включая имена с пробелами.

#### grep — поиск строк внутри файлов

- [ ] Отличать поиск файлов через `find` от поиска в содержимом через `grep`.
- [ ] Объяснять различия между обычным поиском, `-i` и `-w`.
- [ ] Использовать `-n`, `-v`, `-c`, `-l`; помнить, что `-c` считает строки.
- [ ] Искать в подкаталогах через `-r` и ограничивать файлы через `--include`.
- [ ] Различать буквальный текст (`-F`) и регулярные выражения.
- [ ] Применять `.`, `^`, `$` и альтернативы с группировкой при `-E`.
- [ ] Отличать отсутствие совпадений от ошибки по кодам завершения `0`, `1`, `2`.

#### practice — самостоятельные упражнения

`bash/practice/` — каталог учебных файлов, а не отдельная команда.

- [ ] Выполнить задания из `bash/find/notes.md` и `bash/grep/notes.md`.
- [ ] Перед запуском команды предсказать результат, затем объяснить вывод.
- [ ] Проверить поиск на вложенных каталогах, скрытых файлах,
  именах с пробелами и разным регистром.
- [ ] Самостоятельно найти все `.log` файлы и строки с отдельным словом `error`
  без учёта регистра, используя изученные команды.
- [ ] Добавить свой небольшой пример в учебные данные и сохранить
  понятную команду с комментарием в соответствующем `examples.sh`.
